# Settings Organization

Task 12 organizes the main Settings screen into clear user-facing sections without changing the existing settings destinations or underlying settings providers.

## Main sections

- Appearance — system, light, or dark theme.
- Language — current language selection and future Urdu availability.
- Account — existing account/sign-in screen.
- Prayer — existing Prayer & Fiqh Rules screen.
- Notifications — existing notification settings screen.
- Data & Storage — existing sync, export, and import screen.
- About — application information and version.

The organization is intentionally presentation-only. Existing account, notification, theme, data, and synchronization behavior remains in its current architecture.
